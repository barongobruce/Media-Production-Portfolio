## Features
- Browse professional photos across categories: Corporate, Weddings, Studio, Baby Shower, Outdoors.  
- Interactive SPA built with HTML, CSS, and JavaScript.  
- Search photos by captions.  
- Filter photos by category.  
- Like/unlike photos with persistent state using localStorage.  
- Responsive layout for desktop and mobile screens.
